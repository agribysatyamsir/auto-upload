# SEO PLAYBOOK (user ke professional example se compiled)
SEO Agent har topic ke liye isi structure se title/description/tags banata hai.
Goal: search + suggested dono se traffic — exam-aspirant audience (trending) +
evergreen agriculture keywords.

## 1. TITLE (≤100 chars, YouTube limit)
Formula: "<CORE KEYWORD> in Agriculture: <ANGLE> | <EXAM SUFFIX>"
- Core keyword SABSE PEHLE (search weight front-loaded)
- Angle = Types/Benefits/Disadvantages/Methods/Differences jaisa promise
- Suffix = trending exam pair: "AGTA & AFO" / "ICAR JRF" / "IBPS AFO" /
  "NABARD Grade A" / "BPSC BAO" (topic-wise rotate)
- Power words: Complete, Master, Explained, Important MCQs
- KABHI nahi: clickbait jhooth, ALL-CAPS spam, 100+ chars

## 2. DESCRIPTION (order strict — pehli 2 lines search me dikhti hain)
PARA-1 HOOK (2-3 lines): aspirant ka pain question ("confused with X vs Y?")
+ "in this video we break down … in under 15 minutes" + "watch till the end"
PARA-2 OVERVIEW (3-4 lines): concept mastery + importance + exam list
(UPSSSC AGTA, IBPS AFO, NABARD Grade A, FCI, BPSC BAO, ICAR JRF)
PARA-3: "In this detailed lecture, we cover:" + 5-7 bullets:
  • definition/objectives • types with examples (organic/inorganic etc)
  • mechanisms/benefits • limitations • exam MCQs/expected questions
PARA-4 NOTE-NUDGE: "take notes of critical data points … stay ahead"
PARA-5 JOIN BLOCK: FIXED — har video me IDENTICAL (yaml se aata hai)
PARA-6: hashtags line (#Topic #Exam … 10-12)
PARA-7: tags line (comma-separated ~30)
PARA-8: keywords line (comma-separated ~35 long-tail + trending)

## 3. TAGS (YouTube tags field ≤500 chars)
Mix: 40% topic-variants (types of X, X advantages) + 30% exam-names
(upsssc agta agronomy, ibps afo preparation) + 30% long-tail
(X paper thickness, soil moisture conservation)

## 4. HASHTAGS (10-12)
2 broad (#Agriculture #Agronomy) + 4 topic (#Mulching #SoilConservation) +
4 exam (#UPSSSCAGTA #IBPSAFO #ICARJRF) + 2 trending (#AgricultureExams)

## 5. TRENDING RULE (SEO hamesha trending)
Har pack me trending-pool se kam se kam 3 tokens LAZMI:
exam vacancy phrases ("agta new vacancy"), prep phrases
("agriculture competitive exams"), current-year exam names.
Pool yaml me hai — naye trend aane par sirf yaml update karo.

## 6. KEYWORDS LINE (~35)
Topic long-tail + exam long-tail + channel-name phrases + 2-3 trending-pool.
Ye description ke END me plain comma-list (search surface badhata hai).
